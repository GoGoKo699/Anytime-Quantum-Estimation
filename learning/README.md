# Learn Anytime Quantum Estimation

A phase estimator can be efficient when its stopping budget is chosen in advance. This project asks what changes when the same run keeps publishing more precise answers and its entire published history must be trustworthy. Its expiring-sampler extension asks the same question when each reversible source has only a bounded local lifetime.

The single educational anchor is **Michael A. Nielsen and Isaac L. Chuang, _Quantum Computation and Quantum Information_, 10th Anniversary Edition (Cambridge University Press, 2010)**, [book DOI](https://doi.org/10.1017/CBO9780511976667). Begin with the [anchor bridge](anchor-bridge.md), then follow the [30-milestone map](milestones.md). Both this repository and [Quantum Mean Replay](https://github.com/GoGoKo699/Quantum-Mean-Replay) use this source, with project-specific routes.

The map retains 13 background milestones and 17 narrative milestones. Background connects phase queries, physical instruments, joint probability, bandwidth and Cantor geometry. The narrative assembles propagation and first errors into the original phase law, then extends that mechanism to bounded replay using finite-twirl channel polynomials and blocks grouped by actual calls. These are common understanding targets, independent of anyone's assessment history.

For exact statements, go directly to [model and results](../science/model-and-results.md) and the standalone [expiring-sampler extension](../science/expiring-samplers.md). The [scientific route](../science/README.md) maps proof dependencies. The [verification guide](../verification/README.md) describes finite checks and their limits; numerical schedules do not prove the universal lower theorem.
